# Swarm Consensus Orchestrator Skill

## Purpose
This skill coordinates high-end domain planning swarms for `WALmaster`. It enforces the multi-round adversarial consensus pipeline, guarantees zero-contradiction synthesis, and manages the execution handoff to the cheap grunt squad and the Opus 5.5 Deep-Task Specialist Grunt.

## Cohort Model Pinning
* All 4 Domain Planning Consultants operate as a synchronized group on the same selected frontier model: **Opus 5.5**, **Gemini 4**, or **Fable 5.1**.
* All Claude calls route strictly through the user's **Claude subscription bridge**.

## Execution Stages
1. **Round 1 (Full-Scope Domain Drafting):**
   * Domain 1: Storage & Win32 VFS Concurrency Physicist
   * Domain 2: Electron Runtime & IPC Architecture Specialist
   * Domain 3: Event-Sourced Storage & CRDT Reconciliation Theorist
   * Domain 4: Chaos Engineering & Formal Verification Redteam
   * *Output:* Each domain writes a complete implementation plan covering the entire request from their lens.
2. **Round 2 (All-to-All Peer Redteaming):**
   * Every domain reviews and critiques the other three initial plans ($A \leftrightarrow B \leftrightarrow C \leftrightarrow D$).
3. **Round 3 (Second Draft Revision):**
   * Each domain updates their plan incorporating peer feedback.
4. **Round 4 (Final Peer Review):**
   * Second drafts undergo a final critique sweep.
5. **Round 5 (Clean-Context Synthesis):**
   * Fresh instances of each domain planner (unpolluted by debate transcript) review the 3 draft plans of their peers and synthesize one final consolidated plan each.
6. **Round 6 (Deterministic Contradiction Scanning):**
   * Synthesized plans are checked for contradictions in file boundaries, lock mechanics, IPC payloads, and invariants.
7. **Round 7 (Collaborative Contradiction Resolution):**
   * Contradictory clauses only are returned to original drafting contexts for resolution.
8. **Round 8 (Master Execution Plan):**
   * Contradiction-free master atomic tasks are written to `B:\WALmaster\.development\artifacts\planning/`.

## Grunt Dispatch Contract
* 2-to-5-minute atomic tasks $\rightarrow$ Standard Grunts on fast, low-cost models.
* Unsliceable complex tasks requiring deep context and high reasoning $\rightarrow$ **Opus 5.5 Deep-Task Specialist Grunt**.
