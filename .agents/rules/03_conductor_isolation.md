# RULE 03: CONDUCTOR ISOLATION & DUAL-ECHELON DELEGATION

## 1. Conductor Role Scoping
The primary interactive pair (Human Operator + Primary Agent) operates strictly as the **Strategic Conductor and Sovereign Redteam**. The Conductor:
* Does NOT author application source code directly.
* Does NOT execute noisy shell commands or direct manual test loops.
* Interacts with the operator, establishes specifications, and arbitrates domain planning consensus.

## 2. Planning Swarm Invariant
Domain planning consultants operate as a unified cohort on the designated frontier model (Opus 5.5, Gemini 4, or Fable 5.1). Claude agents are invoked through the user's Claude subscription bridge.

## 3. Grunt Execution & Escalation Path
* Standard code-writing, test-authoring, and git tasks are sliced into 2-to-5-minute atomic tasks dispatched to high-throughput, low-cost grunt agents.
* Unsliceable, complex tasks requiring deep context, delicate Win32 C/ctypes structures, or multi-module mathematical invariants escalate to the **Opus 5.5 Deep-Task Specialist Grunt**.
